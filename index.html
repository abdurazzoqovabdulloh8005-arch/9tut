            Desktopingizdagi Cisco Packet Tracer yorlig'ini bosing. Dastur ochilganda pastki chap burchakda tarmoq qurilmalari joylashgan.

            • Switchlar: Cisco 2960

            • Routerlar: Cisco 2811 yoki 1941

            • Kompyuterlar: PC yoki IP Phone.

            Qurilmaning ustiga bosing ➔ CLI tabiga o'ting. Ushbu dasturimizning "🛠️ Amaliy Lablar" bo'limidan berilgan yechim buyruqlarini bosqichma-bosqich kiriting.

⚡ Cisco CCNA Buyruqlar Lug'ati (Cheat Sheet)

        
Imtihon va amaliy laboratoriyalarda eng ko'p ishlatiladigan buyruqlar

      


      

        

          
📁 VLAN & Access Portlar

          

            
vlan 10VLAN 10 yaratish

            
name SalesVLANga nom berish

            
int e0/1Portga kirish

            
switchport mode accessPortni access qilish

            
switchport access vlan 10VLAN 10 ga ulash

            
switchport voice vlan 11Voice VLAN sozlash

            
show vlan briefVLANlarni tekshirish

          

        


        

          
🔗 Trunking & Native VLAN

          

            
switchport mode trunkTrunk rejimini yoqish

            
switchport trunk encapsulation dot1q802.1Q enkapsulyatsiya

            
switchport trunk allowed vlan 10,20Ruxsat berilgan VLANlar

            
switchport trunk native vlan 99Native VLAN o'rnatish

            
show interfaces trunkTrunk holatini ko'rish

          

        


        

          
🌐 Routing & OSPF

          

            
ip route 0.0.0.0 0.0.0.0 <GW>Default route

            
router ospf 10OSPF boshlash

            
network 10.0.0.0 0.0.0.255 area 0Tarmoq qo'shish

            
show ip routeMarshrut jadvali

            
show ip ospf neighborOSPF qo'shnilari

          

        


        

          
🛡️ Port Security & Xavfsizlik

          

            
switchport port-securityPort security yoqish

            
switchport port-security maximum 2Maksimal MAC soni

            
switchport port-security violation restrictBuzilishdagi chora

            
switchport port-security mac-address stickySticky MAC
